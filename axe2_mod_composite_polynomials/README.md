# Axe II — Polynômes faibles modulo un entier composite m (OR<sub>n</sub>, THR<sub>n, t</sub>, MAJ<sub>n</sub>, MOD<sub>k</sub>)

Ce dossier autonome rassemble **41 scripts** Python/Numba (40 scripts de recherche dans `src/` + 1 vérificateur exact `lean/verify_proof_steps_exact.py`), **33 fichiers de résultats JSON** (`results/`), **18 figures** (`figures/`), le manuscrit LaTeX autonome (`paper/`), le projet Lean 4 (`lean/`) et le rapport complet **[RAPPORT.md](RAPPORT.md)**.

## Documents et formalisation

- **[RAPPORT.md](RAPPORT.md)** — Monographie complète de l'Axe II (Expériences E11 à E15o, 26 théorèmes `M1, M2, G1–G5, G3++, T1, T2, Q1, P1, U1–U4, D1–D10`, 18 figures et bibliographie dédiée).
- **[paper/weak_poly_composite.tex](paper/weak_poly_composite.tex)** (avec [paper/references.bib](paper/references.bib)) — Manuscrit LaTeX autonome (anglais, format arXiv) synthétisant `G3++`, `G5`, `P1`, `D3–D10` et `U1–U4`.
- **[lean/README.md](lean/README.md)** — Projet Lean 4 (`v4.16.0` + Mathlib 4) formalisant les briques clés (`G3++`, `G5`, `Lemme D3a`, `D4`, `D5`, `D6`, `D7`, `D8`, `D9`, `D10`, `U3`, `U4`), accompagné du vérificateur arithmétique exact exécutable [lean/verify_proof_steps_exact.py](lean/verify_proof_steps_exact.py).

## Reproduire les calculs

Dépendances : Python 3.14, `numpy`, `numba`, `matplotlib`. Exemples d'exécution depuis la racine de cet axe (`axe2_mod_composite_polynomials/`) :

```powershell
python -u lean/verify_proof_steps_exact.py
python -u src/exact_mixed_1_2_mod6.py
python -u src/theorem_d8_lucas_vandermonde_cw.py
python -u src/theorem_d10_tilted_weyl_and_rank1.py
```
